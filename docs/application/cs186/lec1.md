# Lecture 1：Introduction

本课程主要讲的是关系型数据库 RDBMS，其以 SQL 为主要查询语言，具有成熟的 ACID 机制，且在市场上有广泛的应用。

## 数据库业界的变化

随着云计算的普及，云端部署的数据库不再那么以关系型数据库为中心，NoSQL、图数据库等新兴数据库也是比较常见的。需要指出的是，一款数据库不能 cover 所有的应用场景，但是通常会有一个 Main Memory Database。

在数据分析领域，存在一些为了分析数据而必须进行的清理、整合等工作，这被称作 ETL（提取-转换-加载）。

这些变化的原因包含：

- 硬件/存储技术的变化：RAM/SSD/GPU 等
- 平台的变化：云计算、弹性计算
- 规模的扩大：存储空间和事务扩展
- 新的数据类型：文本、json、图像、视频等
- 新的工作负载：机器学习、高级分析等

## 课程内容

因此，课程不会完全按照书本来讲授，而是聚焦于一些基础的系统概念，让学生能够更好的使用现有的数据库，并尝试创造一些新的数据库。

学习内容包括：

- SQL 编程
- 数据库设计基础
    - 存储与索引
    - 查询与优化
- 事务
- 数据建模：数据的应用级别表示
